# RAC Etiquetas
Aplicativo nativo Android de etiquetas térmicas para a Rodrigues Açaí e Cia.

- Funciona offline e sem login/Firebase.
- Modelos prontos: PEDIDO DA FABÍOLA, PEDIDO DO FRANCISCO, PEDIDO DE, RETIRADA, ENTREGA, CASADINHO.
- Editor de texto, observação, fonte, negrito, caixa alta, alinhamento, borda, tamanho 58/80 mm, cópias.
- Permite salvar modelos no aparelho (pressionar e segurar para excluir).
- Prévia real das etiquetas, impressão pelo sistema Android (RAC Print) e salvar PDF.
- Build APK pelo GitHub Actions workflow RAC Etiquetas APK.

O app é independente do Rodrigues Gestor existente e não acessa banco de dados nem altera pedidos.
